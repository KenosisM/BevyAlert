# 进度与绕行恢复

`recovery.rs` 使用正式模拟的位置、命令ID、独占目标和交通决定。约一秒
没有路线进展且没有足够净位移时记录诊断；持续抖动不会累加成前进。
正常窄口排队及展开等待单独标记，保留它们的实际无进展历时。
共同收缩的短行程成员也使用有限协调等待；只有最慢成员的实际共同进度
产生至少0.2格对应位移才续期一秒。共同进度停止后仍进入普通恢复，不用
移动参考点或重置个体无进展年龄维持等待。
同组仍有实际进展时，目标入口及近目标的停车等待也单独记录。自动修复
同一个命令的失效目标不会重置无进展年龄；新用户命令才开始新的观测版本。

恢复先尝试保持选边的短时让行，再寻找局部让行点，然后请求局部路径。
恢复路径用剩余路径长度评价进展，允许暂时远离最终目标。它只改变求解前
期望速度，仍经过正式ORCA、整段碰撞复核及原到达判定；临时任务不算完成。
每条临时任务有自己的剩余距离基准，避免新长路径继承旧短任务的距离最小值。
切换任务只重设距离原点，不刷新无进展年龄；沿新路线同时产生足够净位移
和剩余距离下降后，才记录实际前进。原地抖动仍会升级为恢复或运动受阻。

闲置、已停靠及明确调度停等且已静止的确定占位形成可撤销硬障碍；活动单位的半秒预测只增加
搜索代价，每次更新即过期。短暂互顶不会被永久写成墙体。分数停靠位置
使用半个停靠间距的路线图，物理边仍调用统一圆盘/扫掠判据。
普通移动单位仅因速度暂时为零不会成为硬障碍；仍在减速的停等单位也保持
移动预测。重新放行即撤回对应硬占位，确定占位变化后重新核实旧的运动
受阻结果，保留原命令、预约、排队年龄及无进展历时。
持续无进展且已静止的活动单位还提供逐步重核的局部占位，恢复路线绕过
这些位置；恢复移动即撤回，普通短暂停顿仍只提供移动预测。它们不改变
静态可达性版本，也不反复作废整个搜索队列。临时占位阻断搜索时，使用
同一展开预算复核不含临时占位的路线：静态仍可达则保留命令并冷却重试，
真正静态无路才保持 `NoRoute`。占位位置产生足够净变化后可重新复核运动
受阻状态，累计无进展时间不重置。
临时占位使局部通路反复等待时，恢复协调器还请求展开区复核。交通层可
让附近一个临时停等成员驶入已预约的安全侧让点，待局部受阻成员离开后
回到原展开点。实际运动仍经过ORCA与连续接触复核，最终停车位和命令
不变；侧让与返回都不计入到达。任务保留命令和目标版本，改令或目标
修复后旧任务不能覆盖新指令，窄口保护仍有优先权。侧让十二秒仍未完成
即交还普通展开与局部恢复；重新申请保留首次复核年龄，原命令、预约和
累计无进展时间不重置。临时任务到期不会改变单位真实位置或完成状态。
近端停靠查询也不把活动命令的接触暂停写进硬占位；真正闲置、已停靠及
明确入口或交通等待占位仍保留，移动接触继续由动态避碰和碰撞复核处理。

`nav::PathSearch` 与普通A*共用展开实现。近端停靠、个体恢复及集群绕行共用公平队列，
按上次服务时刻、首次申请年龄、命令和单位ID轮转。恢复最多八个活动搜索，
每次64次展开，三类重规划每tick共享总额512。目标位置修复也由同一协调器
按命令轮转，每tick最多一个命令、失败后的冷却以半秒计。
预算结束返回 `Pending` 并保留堆、距离和父节点；仅搜索集合耗尽才报告
该区域无路。局部区域可扩大，地图或确定占位改变后重新核实旧结果。
命令ID和目标版本随搜索保留，过期结果不能覆盖新命令。
每步最多接入八个恢复搜索，包含可达性复核；可行的局部起点共同参与
搜索。完成结果先重新连接当前真实位置并核对剩余线段，旧起点或新占位
使连接失效时重新排队，不能直接沿已失效的搜索快照行进。

`Monitoring`、`ScheduledWait`、`Yielding`、`Pocket`、`Queued`、`Searching`、
`Following`、`NoRoute`、`WaitingForSpace`、`Blocked` 区分观测、临时等待、恢复与失败
原因。命令和预约不会因搜索预算或无进展被取消，也不会被标记成停车完成。
局部区域耗尽或目标失效时请求通行与空间复核；重新申请保留等待年龄，已
进入窄口的资格保持原方向，只有尚未启动的旧资格可撤回排队。目标只有在
实际位置失效时才进入位置修复，不为清零停滞而交换仍有效的预约。
CSV记录展开额、队列年龄、无进展时间、过期结果及恢复事件；总模拟耗时
包含恢复计算。输出只由场景运行者在热循环外写入。
单位快照还记录原始请求速度及上限、平滑偏好、交通临时目标和上限、展开
目标及等待原因、恢复任务目标、接触和交通暂停，用于区分规划等待与运动受阻。
单位再次同时产生足够净位移和真实路线进展时，撤回尚未完成的排队或搜索
请求，释放旧任务；小幅抖动不会撤回请求。已有静态场提供一段短路线作为
局部搜索目标，逐段检查圆盘通行；不会为一个跨墙终点反复穷举排除了已知
绕路的矩形区域。这里只重建已有路线前缀，搜索仍使用同一个展开预算。
局部目标避开确定的停止占位；已确认无路时保留诊断和等待年龄，地图、
确定占位或目标版本改变后再重新核实，旧静态场不会刷新该等待时间。
普通命令的远距离进展也读取原静态路线距离，因绕墙暂时远离最终点不会
被误判为停滞；局部任务及最终停车继续使用各自的剩余路线与到达判据。
展开区内部仍有静态阻挡时也继续使用已有地形引导，直到能够直接进入
各自目标区域；不会仅因进入较大的区域半径就为每个单位重解跨墙路径。
近端路径的 `SearchBudget` 与实际局部无路分别报告；没有预算时不把空结果
解释成无路。恢复路径再次无进展会进入明确的重试，有限次数后报告运动
受阻，保留原命令与累计无进展时间；实际前进后再重新评估。

宽阔障碍旁的集群可用实际队形包围圆规划一条共同的地形绕行路线，避免
点单位的共同流场将整群压向同一墙角。该搜索仍调用统一A*和同一公平预算，
与近端停靠、个体恢复按类别轮转，不另开无限额搜索。仅合并共线网格边，
保留路径代价及整段物理通行检查；实际质心推进路线，单位保留自己的相对
偏移。预算等待时仍同时移动，目标只在整群扫掠安全的短前方，不设置启动
延迟。路线结束后接回原展开位置及最终预约，临时路径不改变完成条件。
临时展开点与静态边界之间还预留一个最大同伴直径的通行空间，避免
先到成员停在出口墙边后封住后续成员的纵向通路；最终预约、单位物理
半径和运动检查不变，额外空间只用于选择临时停等位置。
包围圆无法通过时只记录该集群路线不可用，保留单位导航和窄口调度；这不
等于单位无路或已完成。命令或地形版本改变后，旧任务不能覆盖当前命令。
搜索结果接回实际质心时另作完整圆盘扫掠检查；接入不安全或实际队形超出
搜索包围范围时记录集群接入不可用，保留原命令。原停靠分配改变会使旧搜索
和准备展开位置失效；已进入展开后发生修复时转回个体停靠，已停稳成员保留
其实际位置。共同地形路线结束前，前排也保持共同路线，避免提前转向停车。
流场的Bellman分数完全相等时优先斜向推进，提前完成等价转弯，避免方向
遍历顺序将转弯统一推迟至墙前。距离、边代价、切角与物理通行条件均保持。
展开阶段的共享引导也核对同一局部查询中的已确认占位；下一步被临时停靠
成员挡住时，切回带预算的近端路线，绕过占位前往自己的目标。不能仅因
静态地形仍可通行就持续指向已占用的共享源点，预算等待继续单独报告。
