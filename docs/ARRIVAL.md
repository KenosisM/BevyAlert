# 减速、命令完成与稳定停车

独占停靠命令使用 `arrival::Arrival`，与窗口和无头场景共用固定步长核心。
命令状态分为 `Accepted`、`Active`、`Completed`、`Cancelled` 和 `Failed`，
初始无命令为 `Idle`。运动状态独立区分 `Moving`、`Arriving`、`Waiting`、
`Replanning` 和 `Settled`；等待注明停止、空间、入口或近端路径原因。
拒绝的新请求保留旧命令，由下令返回值报告，不能把旧命令错误标成失败。

近端导航给出当前路径剩余长度，包含未走完的转角和浮点停靠点。控制器
按制动需求生成期望速度，并保证一个固定步的路程不越过剩余停止距离。
远端共享流场仍在制动区域之外；近端直通时使用真实目标距离，绕障时使用
实际折线路程。速度层的引导和接触检查继续工作，但不能突破到达速度上限。
没有独占停靠目标的历史对照保留旧减速曲线。

到达只观察接触检查后实际提交的位置和速度：距停靠点不超过0.15格、速度
不超过0.05格/秒，并连续保持0.5秒，才进入 `Settled`、完成命令。时间按
实际固定步的秒数累积；离开范围、速度过大或路径/位置受阻会清空保持时间。
近端点导航的0.05格停止容差继续独立于0.45格物理半径和上述到达定义。

完成后保留命令编号、目标和预约，期望速度为零；不再用普通分离力推动它。
累计记录停稳锚点后的最大漂移。重新离开停靠的距离阈值为0.30格，与进入
阈值分开；超出时明确唤醒并重规划，不能继续显示已到达。目标失效或更换
也会重置到达过程，冻结目标的正常不变性仍由预约管理器保证。

`play::stop_selected` 明确停止并保留命令/预约；`wake_selected` 用原因标注
恢复或让路任务唤醒，重新累计安静时间；`cancel_selected` 释放预约并保留
当前位置。新命令重新进入 `Accepted`。停止不会因为自动修复了目标而恢复，
已取消的命令也不能通过恢复接口复活。游戏对选中单位、演示对当前全部单位
提供H停止、U恢复、X取消；Space仍只暂停整个演示时钟。

CSV的 `arrived` 为真实完成数，`active` 不再包含已完成单位。等待摘要、
接近、停止、重规划、失败及最大停稳漂移均可观察；单位末态还包含运动/
命令状态和连续安静秒数。digest包含命令与运动状态，排除观察计时。
离散对照及没有独占目标的旧输入使用 `not-ready`，不伪造到达数。
