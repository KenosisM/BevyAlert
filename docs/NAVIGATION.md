# 统一导航通行与代价

`nav::step_cost` 定义唯一的相邻有向边：起终点必须可走、移动不超过一格，
对角按网格 `cut_corners` 判断两翼。成本为**进入目标格的地形成本 × 步长**。
`step_cost_extra` 用同一切角判据合并动态阻挡；动态侧翼也参与判断。
方向表只有 `nav` 中的一份，实际离散移动和其他调用点复用它。

`CostGrid` 提供给移动系统前应使用 `erode_grid` 转换为单位锚点空间，足迹
完全合法的锚点才可走，成本继承覆盖到的最慢地形。A*、流场和实际迈步
使用同一张锚点网格；非法足迹或不完整网格拒绝求解。

A* 沿前向边搜索；流场从目标反向扩展时使用原图的**入边成本**。
方向选取满足“当前到邻格成本 + 邻格剩余成本”最小值，不仅比较邻格距离。
单源调用多源实现，避免两份算法分化。失败重算清空旧种子与方向，路线
提取失败清空部分输出；实际选步和炮塔前瞻也验证合法有向边。

连续积分目前用 `segment_allowed` 遍历点中心轨迹经过的网格边，拒绝跨墙
和非法对角，轴向滑动也走同一规则。单位圆盘半径及接触投影约束属于
进一步的连续碰撞工作，此处不把点中心合法当作完整碰撞安全证明。

下令先过滤不存在、重复、非地面及非法位置的单位；每个候选单位必须能
提取真实路线才接单。不可达者保留原命令，返回值只统计实际接单者；无
有效目标返回零，共享命令ID只在至少一名单位接单后分配。

性质回归用独立邻接矩阵和 Floyd-Warshall 对照 48 张小型随机加权图，
共 19,200 对端点的 A*、单源流场与提取路径成本，并校验多源最优距离。
另测封闭夹角、单侧切角、动态侧翼、边缘、足迹、失效重算、不可达命令
以及正式移动系统绕墙。修正导航会有意改变初始旧轨迹，初始行为数据
仍保留在 [历史基线](NAV_BASELINE.md)，不通过改写历史指纹制造通过。
