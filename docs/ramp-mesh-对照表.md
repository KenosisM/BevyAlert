# RAMP 与 MESH 顶端斜面对照表

逻辑地表 mesh 的唯一依据：**地图里每格的高度（level）+ 该格的 ramp 编号**。

- 一格 = 一个菱形四边形，四个顶点是菱形的四个尖点（上 / 右 / 下 / 左）。
- 四角高度 = `level + 表值`，表值单位 = 1 层 = 15px（`LEVEL_HEIGHT`）。
- 表来自 FA2sp `Ext/CMapData/Body.h:33` 的 `RampTypes`（20 项，`RampType` 字段 1~20）。
  FA2 的下标 0~19 对应本表 1~20；0 表示平砖。

## 尖点与地图坐标的对应

`screenX = 30*(Y-X)`、`screenY = 15*(X+Y)`（FA2sp `CIsoView.cpp:58-62`），格 `(X,Y)`：

| 尖点 | 地图顶点 | FA2 VertexType |
|---|---|---|
| 上 | (X, Y) | Top |
| 右 | (X, Y+1) | Right |
| 下 | (X+1, Y+1) | Bottom |
| 左 | (X+1, Y) | Left |

表值 = 相对本格 level 抬高几层。屏幕描述里的「上坡」= 屏幕 y 减小。

| ramp | 上 | 右 | 下 | 左 | 顶端斜面是什么样 |
|---|---|---|---|---|---|
| 0 | 0 | 0 | 0 | 0 | 平 |

| 3 | 1 | 0 | 0 | 1 | 上、左两尖点高 1 层：沿 −Y 方向上升 |
| 4 | 1 | 1 | 0 | 0 | 上、右两尖点高 1 层：沿 −X 方向上升 |
| 5 | 0 | 0 | 1 | 0 | 只有下尖点高 1 层（三角坡，坡面朝下） |
| 6 | 0 | 0 | 0 | 1 | 只有左尖点高 1 层 |

## 相邻两格怎么接

一个顶点被四格共享。本格的四条边与邻居的对应（`i` = 边序，两端角 `(i, i+1)`）：

| 边 i | 本格两端 | 相邻格 | 邻居在同一对顶点上的两个角 |
|---|---|---|---|
| 0 上→右 | 上, 右 | (X−1, Y) | 左, 右 |
| 1 右→下 | 右, 下 | (X, Y+1) | 上, 左 |
| 2 下→左 | 下, 左 | (X+1, Y) | 右, 上 |
| 3 左→上 | 左, 上 | (X, Y−1) | 左, 上 |

判定某一侧要不要补竖直面：比较这条边两端、本格与邻居的**实际高度**（含各自 ramp）。
只要有一端本格高于邻居，就沿这条边补一块四边形，顶边 = 本格两端，底边 = 邻居两端。

> 旧代码的邻居索引是 `0→(X,Y−1) / 1→(X+1,Y) / 2→(X,Y+1) / 3→(X−1,Y)`，与上表整体错位一格 ——
> 竖直面被贴到了错误的边上，这是边缘呈锯齿的直接原因。
