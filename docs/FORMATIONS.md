# 目标区与独占停靠点

`play::issue_orders_at` 先识别同一批命令中全部即将离开的单位，再为每群
规划可达目标区。预约表在所有规划成功后一次提交；失败不丢弃旧命令、
旧预约或消耗命令编号。返回值区分成功、部分不可达、断连、容量不足和
批次中止。它不会更改单位位置，也不添加出发延迟。

`formation::Reservations` 跨集群持有停靠点。候选位置须满足共享导航连通性、
圆盘静态合法性，以及对其他预约和非离开占位者的半径加间隙约束。默认
半径仍为0.45、间距1.1；不足时向外扩展，不足以容纳整群则返回等待空间。
格点相位回退允许单格宽的目标区域。实际停靠点是浮点位置，不能用四舍五入
后的导航格代替预约或到达距离。

初始配对使用空间分区排序和有界局部交换。接近目标区时仍共享远端流场；
近端转向各自停靠点，必要时使用短路径。入口事件只在原有横向列内调整
尚未进入者的前后次序，让先进入者填深处。预约位置集合不变；进入后冻结
配对，只有位置失效才重申请。入口等待检查更深位置的占有者，并保留通道，
不会将整群设置为错峰出发。

有独占停靠点的单位关闭旧重力碗的压实压力梯度，避免长程行进持续打乱
横向次序；保留分离、相遇避让提议和完整连续碰撞约束。旧对照单位的压力
行为保持原样，后续速度避障可替换这一引导层。

`local_nav` 的近端路径复用 `nav::find_path_filtered` 和 `collision` 的圆盘
边检查。半间距格点表达浮点停靠位置附近的空隙；原导航格回退保留狭窄地形
走廊。静止占位者、入口等待者和上一tick被安全回退停住的单位参与局部查询。
缓存按命令和目标区共享，路径边再次检查；不存在另一份地形通行规则。
临时无局部路径会保留命令及预约并显式报告，不传送或取消单位。

连续改令会释放被替换预约；取消和销毁也会释放。`play::cancel_selected` 只
取消所选单位，保留其位置。游戏窗口的X取消选中单位，演示窗口的X取消当前
演示命令。静态网格变化或取消后留下的闲置占位者使某个位置失效时，只为
受影响单位重申请，其他冻结位置和命令编号保持不变。

场景CSV输出 `reservation_count`、`frozen_targets`、`waiting_space`、`waiting_entrance`、
`blocked_near_path`、`command_plan_us`、`formation_us` 和 `entry_refinements`；单位
末态包含实际停靠点和有效/冻结/阻挡状态。维护耗时包含在模拟总耗时内。
0.05格是近端点导航的停止容差，不是单位物理半径，也不是命令完成定义。
停车状态机和稳定性尚未接入，到达指标继续使用 `not-ready`。
