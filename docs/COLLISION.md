# 连续碰撞与接触安全

`collision` 直接读取导航锚点网格的阻挡格；格子范围为格心 ±0.5，地图外部
也阻挡。圆盘扫掠检查格子面及圆角的最早接触，不只检查终点。接触间隙
为 0.0001 格，浮点比较 epsilon 为 0.00001 格；单位半径保持 0.45 格。
进入导航网格前的足迹侵蚀仍由 `nav` 统一处理，不另存地形几何。

积分保留 tick 开始时的合法位置。墙面滑行后的结果再次检查整个旧位置到
新位置的线段；本 tick 公开的运动轨迹始终是这条线段。接触投影每次从
合法位置开始并检查墙体，受墙阻挡的修正份额可分配给另一方。完全重合
使用稳定索引确定分离方向。投影后再次检查整段静态轨迹和所有相对轨迹，
限制相撞提议，并重查跟随者。迭代仍不能满足安全约束时保守停车，保留
目标和命令，不缩小半径或跳到另一个位置。

`Runtime.contacts` 提供各单位 `StaticBoundary`、`InvalidStart`、`Contact`、
`SafetyStop` 原因、未解决接触、轨迹限幅次数及最大穿透。非法初始位置
保持并报告；初始已重叠与从合法分离状态新发生的穿透分别计数，无法容纳
多个圆盘的输入不宣称已经修复。CSV 新增 `swept_penetration`、
`unresolved_contacts`、`illegal_trajectories`、`limited_trajectories`、
`initial_overlaps`、`safety_stops`。`collision_ready` 只在连续模式实际完成检查
后为true；离散旧模式和初始tick的数据使用 `not-ready`，避免把未检查当作
零错误。使用 `--sample-every 1` 可保留每步诊断。

回归覆盖高速跨格、半径贴墙、墙角、地图边缘、受墙约束的推挤、完全重合、
无空间的初始接触、对向和交叉轨迹及跟随者。轨迹断言使用独立 f64 最近
距离，静态断言另用圆盘到格子矩形的距离检查。性质与端到端模拟共用正式
Rust 代码。这里的碰撞限幅是安全回退，复杂群体通过效率、目标预约、停车
和恢复由后续算法完成；安全停止的单位不会被计为到达。
