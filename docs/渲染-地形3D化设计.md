# 地形渲染：3D 高度场（路线已定）

状态：**2026-10-16 用户拍板后的第一版设计**。只定方向，未写实现代码。

## 0. 路线（用户定）

- 地形 = **真 3D 高度场网格**
- 观感 = **保留 RA2 等距**
- 模拟层 = **一起重新设计**（不再照搬 C++）
- 🔴 **不再转译 Westwood 的渲染工艺**：`cpurenderer.cpp`（CPU 参考光栅）和
  `gpurenderer.cpp`（逐精灵 compute dispatch）**两份都不抄**。
  只从旧实现里取**数据**：地图的 `level` / `ramp_type` / `terrain_type` / 砖像素。

## 1. 几何：每格一个四边形，斜坡是真斜面

- RA2 每格一个 `level`（0..18，每级 15px），**格内四角**的抬升由 `ramp_type` 决定
  （`ramp_corner_heights`，`world.rs` 里已有，可直接用）。
- 于是每格就是一个**四边形**，四角高度 = 该格 `level` + 该角的抬升：
  - 平地格 → 4 角等高，是水平的菱形
  - 斜坡格 → 4 角不等，是**真实的斜面** ✅
- 顶点在等距平面上按格角摆放，高度走世界 Y 轴；投影后仍是 RA2 的菱形。
- **整张图一个 mesh**（一次 draw call）：`(W+H)²` 格 × 4 顶点。
  hillbtwn 128×128 ≈ 16k 格 → 65k 顶点，对 GPU 是零头。
- 相邻格共享边的高度必须一致（地图本身满足）；不满足处以哪一侧为准 **待定**。

## 2. 材质：砖的外观怎么来（**待你拍板**）

- **A. 图集**：把用到的 TMP 砖烘成一张纹理图集，每格 UV 指向自己那块砖 —— 最接近 RA2 观感。
- **B. 现代 splat**：`terrain_type` → 少量地表材质混合，完全不要"砖"的外观 —— 最现代，但不像 RA2。
- **C. 混合**：现代 splat 打底，砖的配色/过渡作为参考。

## 3. 相机与遮挡

- 正交相机，等距角度（RA2 的 2:1 投影）。
- 遮挡**交给 GPU 深度缓冲** —— 这正是 3D 化的收益：不再需要画家序、per-pixel zbuf、
  也不再需要"悬崖立面 / 坡道面"这种 2D 概念（悬崖 = 垂直的几何）。

## 4. 直接推翻的东西

| 东西 | 处置 |

| `shaders/sprite_blit.wgsl`（逐精灵 compute dispatch） | **删** |

| `TerrainCell` 的 `zbuf` / `extra` / `extra_z` / `ex_*` / `depth_test` / `write_depth` | **不再用于渲染**（`level` / `ramp_type` / `terrain_type` / `pixels` 留作输入） |
