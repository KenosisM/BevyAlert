# 稳定邻域与接触对查询

`spatial::Index` 存储点或轴对齐包围盒，默认桶边长2.2格。查询遍历实际
范围涉及的所有桶；半径由双方速度、半径和预测时域计算，并保留旧引导
所需的最小范围。当前引导预测一整个固定tick，后续预测求解器可传入更长
时域。没有邻居数量上限，近距离危险对象不会被截断。

输出按稳定单位索引排序、去重；HashMap自身遍历顺序不参与模拟决策。
接触投影按原先的索引对顺序处理。每次位置修正立即更新索引，重新查询
当前单位尚未处理的后续邻居，避免漏掉修正中新出现的接触。连续轨迹对
使用从旧位置到提议末位置的带半径包围盒；接触滑动可能改变包围盒，
每轮重新生成候选对，再检查所有可能相交的相对轨迹。

桶、快照、候选邻居、接触对和原因数组复用容量。超过4096个桶的包围盒
单独保留，过大的查询使用完整枚举回退；不因为范围过大而漏掉单位。
高密度情况下仍可能产生平方数量的真实候选，不能承诺线性复杂度。
单桶超过32项记录密度事件，完整保留查询对象。

`Runtime.spatial_stats` 和CSV提供查询耗时、邻居峰值（含自身）、桶峰值、
查询次数、访问项、去重候选对、截断数、密度事件、大包围盒及回退查询。
`PhaseTimes.spatial` 是快照/接触阶段中索引相关耗时的子项，不与总耗时
相加。连续模式复用本tick的正式接触误差，避免观察指标再次全队两两扫描；
初始布局和离散旧模式仍单独计算旧终点指标。

回归用暴力矩形枚举对照跨桶边界、负坐标、动态更新、不同查询半径、
密集桶和大包围盒；正式模拟另比较索引与暴力查询的逐tick位置、速度及
接触原因。稀疏与密集256/1024查询测量单独运行；此阶段的Dev数据用于
定位开销，完整Release通行和模拟性能验收另行报告。
